# План реализации: Виджеты взаимодействия с ИИ-агентом (Вариант Б)
## Модульные виджеты `agent-response` и `agent-prompt` для PhoneBox Desk Deck

---

## 🎯 Цель
Превратить подключенный планшет/смартфон в полноценный сенсорный пульт управления ИИ-агентом (**Antigravity / Gemini / Claude Code**):
1. **Виджет `agent-response` (Экран ответа агента):** отображает в реальном времени текущие мысли, статус выполнения инструментов и итоговый ответ агента с форматированием Markdown и плавной прокруткой.
2. **Виджет `agent-prompt` (Панель отправки промптов):** поле ввода текста с возможностью голосовой надиктовки через микрофон Android и мгновенной доставкой промпта прямо в чат Antigravity IDE на ПК без необходимости кликать мышью.
